# 智能眼科三病症手机筛查：判断流程与标准整理

- 来源：《智能眼科 斜视+双眼视功能异常筛查.docx》（研究方案稿，2026-09-11 提取，纯文本见 `results/doc_extract.txt`）
- 三个病症：**① 干眼**、**② 老视**、**③ 斜视及双眼视觉异常**
- 性质说明：原文是研究方案（申报书风格），其中部分标准为「设计目标」，多处明确写「待专家补充/明确」——本文把「原文已给出」与「缺失待定」分开列出

---

## ① 干眼智能筛查（专家已确认，文档最完整的方向）

### 判断流程（按文档整理）

```
1. 基础信息采集：年龄、屈光矫正状态、基础视力、近期用眼情况、干眼症状问卷
   环境记录：屏幕亮度、环境光照、观看距离、色温/护眼模式、曝光
2. 练习：10-15 秒，确定起始视标大小与反应速度基线
3. 正式测试：连续视标识别（E 字 / Landolt 环，方向随机）
   · 首期 60 秒自然眨眼测试；症状明显/临界/难判断时延长至 3-5 分钟
   · 逐次记录：视标大小、识别结果、反应时间、出现时刻
4. 前置摄像头同步感知：眨眼、眼睑运动、头部姿态、观看距离
   质量门控：距离变化过大 / 头部偏转明显 / 画面模糊 / 光照不合适 → 提示调整或重测
5. 按眨眼分段为「眨眼间期」，分析两类模式：
   · 模式A：间期内视觉逐渐下降 + 眨眼后较快恢复 → 泪膜稳定性不足
   · 模式B：视觉持续下降 + 眨眼后恢复不明显 → 眼表异常
6. 特征：眨眼频率 / 间隔 / 完整性 + 视觉维持表现 + 反应时间 + 症状问卷 + 环境
   → 多模态风险模型（临床知识约束 + 不确定性校准 + 保形预测）
7. 输出：干眼风险 低 / 中 / 高 三级 + 主要异常指标 + 规范就医建议
   （临界结果自动延长测试；低质量或低置信度 → 拒判/重测）
```

### 原文已给出的标准

| 项 | 内容 |
|---|---|
| 测试时长 | 60s（可延至 3-5 min） |
| 视标 | E 字 / Landolt 环，方向随机 |
| 分段方式 | 眨眼间期 |
| 风险分层 | 低 / 中 / 高（三层） |
| 关联机理 | 视觉维持率、视力破裂时间（爱尔既有思路，被引用为基础） |

### 缺失 / 待明确的指标 ⚠️

| # | 缺失项 | 说明 |
|---|---|---|
| 1 | **视觉维持率 / 视力破裂时间的数值定义** | 「视力下降多少算破裂」「维持率低于多少算异常」——文档只引用了爱尔的概念，无任何阈值 |
| 2 | **眨眼间期「逐渐下降 / 恢复」的量化判据** | 下降幅度、速率、恢复时间的界值均未定义（A/B 两模式的判定目前只能靠模型学习，无规则初值） |
| 3 | **眨眼频率 / 间隔 / 完整性的正常范围** | 未给出（也未引用文献值） |
| 4 | **反应时间劣化的判定标准** | 「反应变慢」无量化 |
| 5 | **低/中/高风险的切点** | 由模型训练得出，但无先验初值，也无「与泪膜破裂时间（BUT）检查结果对齐」的具体映射规则 |
| 6 | **症状问卷量表** | 「干眼症状问卷」未指明用 OSDI 还是其他量表，题目与计分未定 |
| 7 | **混杂因素控制的具体规则** | 提到「转化为损失函数约束」，但年龄/屈光/基础视力的校正公式或分层方法未给出 |

## ② 老视功能筛查（专家未补充，最不完整的方向）

### 判断流程（仅初步设想）

```
近距离视标识别 + 字号/对比度切换 + 近远目标转换任务
  → 记录识别阈值、反应时间、视觉恢复速度、瞳孔或双眼集合反应
  → 探索老视或调节功能下降的风险指标
```

### 原文已给出的标准

**无。** 文档原文（§研究内容二、§科学问题 3、§研究目标）：目标人群、功能指标、临床对照检查、预期技术指标、科学问题表述——**全部标注「由老视专家进一步明确/待定」**。

### 缺失 / 待明确的指标 ⚠️（几乎全部）

| # | 缺失项 |
|---|---|
| 1 | 目标人群与年龄范围 |
| 2 | 视觉任务的具体参数（视标大小档位、切换逻辑、时长） |
| 3 | 判断指标的定义与阈值（识别阈值下降多少、恢复速度多慢判异常） |
| 4 | 临床金标准（调节幅度测量？主观加镜？）与对照方案 |
| 5 | 混杂因素（近视代偿、照明、瞳距） |
| 6 | 风险分层方式 |
| 7 | 科学问题的正式表述 |

**结论：老视方向当前没有任何可执行的手机端判断标准，无法组织开发，必须先由专家补齐。**

## ③ 斜视及双眼视觉异常筛查（定量标准最多的方向）

### 判断流程（四个任务，总时长控制在 3-5 分钟）

```
任务① 注视稳定性测试（角膜映光法等效）—— 第一眼位静态显斜基线
   屏幕中央动态闪烁卡通注视点 → 摄像头定位瞳孔中心 + 角膜映光点（第1 Purkinje 像）
   → 计算每眼映光点-瞳孔中心偏移量，比较双眼对称性
   → 取 3 秒内连续有效帧的偏斜量均值及标准差（HDE 水平 / VDE 垂直，像素→经距离与内参标定→棱镜度△）
任务② 交替遮盖诱发测试 —— 隐斜 / 间歇性斜视
   遮盖标记（手遮挡摄像头/屏幕局部黑屏模拟单眼遮盖）→ 遮盖解除后 0.5 秒内
   检测再注视运动：偏移幅度（△）、复位速度（°/s）、残余偏移量
任务③ 水平/垂直动态追踪 —— 双眼协调
   亮色小球 5-10°/s 移动 → 双眼运动轨迹一致性、主序眼-偏斜眼位置差、
   轨迹交叉相关 → 双眼对称性指数 BSI
任务④ 远近注视切换 —— 集合功能
   近距（33cm 视标）↔ 远距（约 2m 等效视标，缩小视标模拟）交替
   → 集合反应时间、集合偏移量
融合模型：LightGBM/CatBoost 或贝叶斯层次模型
   输入 = 上述标志物 + 年龄 + 屈光状态 + 环境 → 斜视风险概率
可解释性：SHAP/LIME 输出各特征贡献度
质量门控：头部偏转/瞳孔模糊自动剔除帧 + 帧级置信度 → 拒判（「测试质量不佳，请重新测试」）
```

### 原文已给出的定量标准（全部文档中仅有的三条）

| 判定 | 阈值 |
|---|---|
| **高度疑似斜视** | 注视偏差持续 **≥10△（水平）或 ≥5△（垂直）** |
| **可疑阳性** | 交替遮盖诱发再注视偏移 **≥6△** |
| **未见异常** | 其余 |
| 可检测目标 | ≥8△ 水平 / ≥5△ 垂直 |
| 性能目标 | 水平 ≥10△：敏感度 ≥85%、特异度 ≥80%；≥500 例 3-12 岁对照验证 |
| 输出 | 未见异常 / 可疑阳性 / 高度疑似斜视（三级）+ 可解释性报告 |

### 缺失 / 待明确的指标 ⚠️

| # | 缺失项 | 说明 |
|---|---|---|
| 1 | **Hirschberg 系数（像素→△ 换算）** | HDE/VDE 像素转棱镜度需要「每 mm 偏移 ≈ 多少△」系数（文献约 22△/mm，个体差异大）及毫米级瞳孔尺寸标定方法——**文档完全未提**，这是角膜映光法落地的第一技术缺口 |
| 2 | **观测距离与相机内参标定流程** | 「经距离和相机内参标定」只有一句话，标定方法、精度要求未定义 |
| 3 | **「映光点位于瞳孔缘」判显斜的经验值** | 瞳孔缘偏移对应约 15-20△ 的经验文献值未写明 |
| 4 | **再注视偏移的正常儿童常模** | 任务②「依据受试者正常对照数据建立的阈值」——常模数据不存在，依赖未来 ≥500 例研究 |
| 5 | **BSI（双眼对称性指数）正常范围** | 「显著低于正常范围」——正常范围未定义 |
| 6 | **集合反应时间 / 集合偏移量正常范围** | 未定义 |
| 7 | **「2m 等效视标」的缩放换算公式** | 需要视标视角等效计算（视标物理尺寸 × 距离的视角匹配），未给出 |
| 8 | **病种分型鉴别标准** | 间歇性外斜 / 调节性内斜 / 隐斜 / 垂直斜的**相互鉴别判据**未定义（只有总体的三级风险） |
| 9 | **质量门控的量化值** | 「头部偏转过大」「光照不合适」「配合度低」均未量化（角度阈值、照度范围、模糊度指标） |
| 10 | **年龄分层常模数值** | 3-5/6-8/9-12 岁亚组校准为计划，无数值 |
| 11 | **立体视检测的具体判据** | 提到「红蓝滤色片+手机立体图（Titmus 等效）」，但筛查通过/异常的判据未定义 |

## 4. 汇总：有 vs 没有

| 方向 | 判断流程 | 定量阈值 | 完整可执行度 |
|---|---|---|---|
| 干眼 | ✅ 完整（测试→分段→特征→分层） | ❌ 全部缺失（7 项：维持率/破裂时间/眨眼范围/反应时间/风险切点/量表/混杂规则） | **流程可开发，阈值不可判**——需先定界值或纯靠模型+临床对照训练 |
| 老视 | ⚠️ 仅初步设想 | ❌ **完全没有**（7 项全缺，含金标准与人群） | **不可开发**——必须先过专家关 |
| 斜视 | ✅ 最完整（4 任务+模型+拒判+验证方案） | ⚠️ 部分（3 条核心阈值已有：≥10△/≥5△/≥6△；但换算系数、常模、BSI 范围、分型鉴别等 11 项缺失） | **流程可开发，但像素→△ 换算与常模是硬缺口**——没有它们，阈值 △ 无法从摄像头数据算出 |

## 5. 缺失指标的归类与获取途径建议

| 类别 | 涉及缺失项 | 获取途径 |
|---|---|---|
| **临床医学界值** | 干眼 1-5、斜视 3/4/5/6/9/10/11 | 文献检索（各指标的公认界值/常模）+ 爱尔专家补充——文档本身体裁就是「待专家确认」 |
| **换算与标定方法** | 斜视 1/2/7（Hirschberg 系数、内外参、视角等效） | 文献（Hirschberg 系数 ≈22△/mm）+ 自测标定实验（已知 △ 的棱镜/眼位模拟） |
| **自建数据训练** | 干眼 5、斜视 4/10（风险切点与常模） | 文档规划的 ≥500 例临床对照——属研究阶段工作，非规则可实现 |
| **量表与语料** | 干眼 6（症状问卷） | 采用 OSDI 等公开量表 |
