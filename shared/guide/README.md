# 爱科测试演示素材

七张照片级数字人图片，由内置 `image_gen` 以现有 `eyecho_half.png` 为身份参考生成。
四张首批预览已经用户认可；另补闭眼、协助者遮左眼和协助者移开遮盖。
完整提示词见 [prompts.json](prompts.json)。

- `open` / `blink`：自然注视、眨眼闭合瞬间。
- `left` / `right`：自行遮住左眼、右眼。
- `helper_open` / `helper_left` / `helper_right`：协助者移开遮盖、遮左眼、遮右眼。
- 左右以被测者自身为准，正面看时与画面方向相反；禁止镜像图片或标识。
- 透明 PNG 等比缩小到 960×720；保留透明通道。不要在应用中裁切手势或头顶。透明人物直接叠加主题表面，深色模式不出现浅色照片方块。

安卓 `feature:services` 和 iOS 工程直接引用同一份透明 PNG（`res/drawable-nodpi`），不重复存储素材。
iOS 通过 `EyechoGuideImages` 显式按 PNG 文件路径解码并缓存，所有入口统一使用 `EyechoGuideImage` 展示；
Release 模拟器回归会实际渲染七个姿势与服务舞台，检查人物像素并保留截图。
图片仅用于测试准备引导与服务页示范；正式视标、采样、计时和评分不经过这里。
现阶段为图片分镜，不是生成视频；手机移动、E 方向和注视点仍由原生画布讲解。

交替遮眼示范为 12 秒循环：右眼 2 秒、双眼 2 秒、左眼 2 秒、双眼 2 秒，
然后右、左各 1 秒交替两轮。自行遮眼和协助者遮眼分别使用对应图片。
系统减弱动态效果时冻结关键帧，全部分镜文字仍可阅读。
