# 爱科测试演示素材

当前使用九张图片，两端直接打包同一份 `res/drawable-nodpi` 资源，不重复存储。

- `open / blink / left / right`：原有透明人物，自然注视、闭眼、自行遮左/右眼。
- `side_far / side_near`：侧面展示本人遮左眼、手持手机从远到近，供单眼移近法使用。
- `lighting_open / lighting_left / lighting_right`：手机固定在支架上，本人自行遮眼或移开遮盖，协助者仅在手机旁打光。
- 旧 `helper_*` 协助者遮眼图片已从资源中移除；测前选择谁协助均不会切回该场景。
- 左右以被测者自身为准；禁止镜像图片或标识。人物、手机、手势均等比适配，不裁切。

新增五张由内置 image_gen 以用户 2026-11-11 提供的形象为参考生成，身份参考保存在 `reference/eyecho-v2.png`，不打包到应用。动作提示词及来源整理见 [prompts-v2.json](prompts-v2.json)；原始生成记录保留在 [prompts.json](prompts.json)，其中已废弃的 helper 场景不再使用。
新增场景为统一浅灰摄影底，原有人物保留透明通道。应用的演示区域深浅主题均使用浅灰底及深色文字。

iOS 通过 `EyechoGuideImages` 显式按 PNG 路径解码并缓存，保持已修复的真机兼容方式。回归检查实际 SwiftUI 人物渲染，避免只检查文件存在。

目前使用静态照片分镜，不生成 GIF。准备引导、服务页与问号回看共用这些图片；正式视标尺寸和测试协议不经过图片。交替遮盖教学仍为右眼2秒、双眼2秒、左眼2秒、双眼2秒，再左右各1秒交替两轮，动作由本人完成。

所有测试的问号均显示当前环节的演示与文字；查看期间会话时钟、题目等待与相机采样暂停，关闭后继续。系统减弱动态效果时保留关键帧和全部步骤文字。
