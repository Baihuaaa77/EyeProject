# 会话收尾：同步 auto memory

目标：让下一个会话（或换台机器的自己）**只读记忆就能无损接续当前工作**。写入必须遵循 `memory-discipline.md` 的 7 条纪律——尤其是：先检索现有记忆、更新优于新建、单主题、仓库/文档可查的内容不写、新结论直接修正旧记录。

## 执行步骤

1. **扫描本段对话**，按清单提取「跨会话仍有价值」的内容（中间报错、调参过程、一次性的琐碎细节不进记忆）：
   - [ ] 当前任务进行到哪里（阶段/状态）
   - [ ] 已确认的结论（含关键数据/证据）
   - [ ] 做了哪些重要决定 + 每项决定背后的原因或证据
   - [ ] 尝试过但失败的方案 + 失败原因（防止重走弯路）
   - [ ] 修改了哪些关键文件（路径 + 改动要点）
   - [ ] 当前测试结果（跑过什么、过没过、关键数字）
   - [ ] 尚未解决的风险或问题
   - [ ] 下一步具体行动（可执行的第一个动作）

2. **先检索现有记忆**（列出记忆目录全部文件并读 MEMORY.md，记忆目录由 settings 的 `autoMemoryDirectory` 指定，当前为项目根 `memory/`）：
   - 已有同主题文件 → **Edit 更新原文**（合并新信息、修正过时表述），不新建
   - 全新主题且值得跨会话保留 → 新建单主题文件（frontmatter 按 user/feedback/project/reference 归类）+ 在 MEMORY.md 加一行索引
   - 内容已在仓库、CLAUDE.md、模块文档中可查 → 不写入
   - 相对日期转绝对日期（"今天" → 实际日期）

3. **质量自检**：
   - 每条记忆是否自包含——脱离本段对话也能读懂？
   - 旧结论被本轮推翻的 → 直接改写旧记录，不留两个版本
   - 记忆中的路径/配置是否与仓库现状一致（不一致以仓库为准并顺手修正记忆）

4. **无内容可写就明说**：本阶段没有值得跨会话保留的内容时，直接报告「无需更新」，不要为写而写。

## 汇报格式（固定三段）

1. **更新了哪些记忆文件**（新建 / 更新分开列）
2. **每个文件新增或修改了什么**（一句话一条）
3. **下一会话应该从哪一项开始**（具体到第一个动作，可直接被 session-continue 接住）
