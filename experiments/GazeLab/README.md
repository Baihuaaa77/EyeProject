# 屏幕注视追踪

独立安装的 Android 和 iPhone 试验应用，包名 `com.zkyjss.gazelab`。两端共享 MediaPipe Face Landmarker、注视标定和落点算法。前摄画面只在本机内存中处理，标定参数在应用进程退出后清除。

## 构建与使用

```powershell
.\gradlew.bat -p shared :domain:jvmTest
.\gradlew.bat :gaze-lab:assembleDebug
```

APK 位于 `experiments/GazeLab/build/outputs/apk/debug/gaze-lab-debug.apk`。授权相机后，把手机放在实际想使用的角度，点「开始标定」，依次看完九个圆点。落点以白色外环和橙色圆心显示。若要换一个侧放或倾斜角度，点「标定当前姿势」，应用按当前头姿和人脸在画面中的位置选择匹配的记录。画布尺寸改变时需要重新标定。

「验证误差」会依次显示五个独立验点，期间隐藏实时落点。每点取一段有效预测中像素距离的中位数，最终报告五个中位数的中位数、画布对角线百分比和最大值。验点位于画布内部，可用来发现标定偏移，也可分别比较各个摆放角度的表现。

GitHub Actions 的「屏幕注视追踪 iOS IPA」生成未签名的 iPhone 真机 IPA。下载 `gaze-lab-ios-unsigned-ipa` 并解压，然后用 Sideloadly 或 AltStore 重新签名安装。应用最低支持 iOS 16，首次运行需允许相机权限。

iPhone 版从 0.1.1 起每秒分析 6 帧。实时落点用三次估计的中值和时间低通抑制跳点和小幅波动，界面在有效结果之间线性插值。标定和误差验证仍按真实相机样本计算。

## 当前算法与可用范围

- 将虹膜中心投影到眼角局部坐标，用眼角间距归一化。九点样本取中位数，对单眼分别拟合二维映射。双眼结果相差过大时隐藏落点，有单眼映射且信号可用时允许单眼输出。
- 每组映射覆盖标定时相对姿势附近的小范围。闭眼、画面过期、姿势超出范围或推算落点落在画布外时隐藏圆点。当前门限是工程初值。
- 当前管线依赖 MediaPipe 识别人脸和可用眼部关键点。大角度侧脸、前摄只拍到局部眼睛、镜片反光或弱光时，能否追踪取决于真机上的检测质量。
- 目标是扩大可用姿势范围并量化误差。真机验证可保持注视同一目标，分别改变手机横滚、左右偏角、上下倾角和距离，再用五点误差、有效输出率和响应延迟比较。连续大幅移动下的落点需要有大姿态训练数据的三维视线模型，以及适配机型的前摄与屏幕几何。
