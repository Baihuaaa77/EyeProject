# UI 与交互优化验收记录

日期：2026-10-11

## 已完成

- 统一中性灰白/深色表面、蓝色主操作、圆角卡片、字号与留白；统一按钮、返回栏、导航选中态及触摸区域。
- 首页以状态和护眼操作为主，趋势与开发者工具默认折叠。没有有效实时数据时显示“待测”。
- 服务入口改为干眼自测、眼位自测、老视自测。隐藏原占位智能体悬浮入口，“我的”提供真实的权限与通知设置入口。
- 老视与眼位问卷逐题展示，保留年龄、矫正方式、既往病史等原字段。
- 每项正式任务前提供 Canvas 方法示范；确认后才启动计时与正式采样。近视力换眼仍单独确认。
- 距离和光照默认折叠，主区域显示“移近一些”“移远一些”等行动提示，中文语音可关闭。遮盖任务不要求双眼同时可见。
- 干眼流程改为自然眨眼、睁眼两个独立准备阶段，允许随时停止；共享首页相机帧，修复阶段状态、重测及旧眨眼时间混入的问题。
- 应用进入后台时中断测试，返回后重新准备；相机失联、数据不足不会被包装成正常结果。
- 视标保持原有尺寸计算和测距质量门控；黑白对比独立于应用主题。原始详细指标和质量限制保留在完整报告中。

## 医学与设备验证边界

此次改动不宣称临床有效性。风险质量门控及详细报告保留；干眼记录不再直接推断泪膜能力。医学依据参考 [美国国家眼科研究所：干眼检查](https://www.nei.nih.gov/eye-health-information/eye-conditions-and-diseases/dry-eye/testing-dry-eye)：干眼评价涉及泪液量、泪膜稳定性等检查，眨眼计数不等同于这些检查。

按要求未连接真机。相机测距精度、实际中文 TTS、厂商权限行为、设备性能及临床准确性尚未由本次本地测试验证；本地渲染和测试通过不代表已完成设备或临床验收。
