# 三病种测试流程对齐记录

日期：2026-10-11
依据：[智能眼科-整合9.18.docx](./智能眼科-整合9.18.docx) 研究内容一至三；前期分析见 [三病种手机检测流程与实现分析](./三病种手机检测流程与实现分析.md)。

本次把 App 内三项测试的流程、参数和结果输出对齐到文档。文档未定或自相矛盾处，统一在代码的协议对象里给出「实现约定」并标注「候选」，便于专家确认后修改：

- 干眼：`feature/services/.../DryEyeProtocol.kt`
- 老视 / 斜视：`feature/services/.../ScreeningProtocol.kt`

所有分级规则均未经临床验证，结果页明确标注「初筛参考，不能替代眼科诊断」。

## 1 干眼（研究内容一）

| 文档要求 | 实现 | 状态 |
|---|---|---|
| 测前记录年龄、性别、眼病（屈光不正/白内障/青光眼/黄斑/视网膜/眼睑/干眼症）、手术外伤史、隐形眼镜史、近期用药、电子产品时长、眼部化妆、睡眠、全身病（糖尿病/甲状腺/类风湿/干燥综合征）、矫正状态、基础视力、近期用眼、干眼症状 | `dryEyeQuestions` 逐题问卷；症状频率仅在有症状时出现 | 已对齐 |
| 记录屏幕亮度、环境光照、观看距离 | 测试期间窗口亮度固定为最高并记录；光线传感器 lux；0.5 秒一次距离采样 | 已对齐 |
| 提示「建议佩戴最佳矫正视力眼镜进行测试」，距离 40 cm | 准备页提示卡 + 倒计时提示；门禁 40±5 cm | 已对齐 |
| 练习 10–15 秒：视标 0.3 起，错/无反应增大一档；答对后同大小再显示一次，再答对缩小一档；不计入正式结果 | 12 秒练习，`DryEyeStaircase`；练习题不写入正式统计 | 已对齐 |
| 正式：60 秒自然眨眼 + 20 秒睁眼，中间无休息；随机方向 E；每题显示 2 秒，2 秒无反应记错；记录视标大小、正确性、反应时、出现时刻 | 两段连续计时、只切换提示不停顿；`DryEyeTrial` 逐题记录；超时记错 | 已对齐 |
| 结果接近临界或症状明显时延长至 3–5 分钟 | 结果页「延长测试（自然眨眼 3 分钟）」 | 已对齐（取 3 分钟） |
| 补充：闭眼休息 1 分钟或眨眼操后复测 | 结果页「闭眼休息 1 分钟后复测」，与上一次并排对比 | 已对齐（眨眼操未做） |
| 距离变化过大、头部偏转、光照不合适时提示调整或重测 | 实时提示；双眼不可见 > 1.5 秒或距离超出 30–50 cm > 3 秒判中断，结果标记无效 | 已对齐 |
| 正常眨眼 10–16 次/分钟；正常眨眼间隔 > 10 秒 | 自然眨眼段算频率；「间隔 > 10 秒」按睁眼段最长持续睁眼时间解释 | 已对齐（解释见约定 4） |
| 输出：数据是否有效、风险等级、主要异常指标、就医建议 | 结果卡四项齐全；完整指标折叠；原始数据存 `dryeye_*.json` | 已对齐 |
| 眨眼间期分析 | 输出「眨眼前 2 秒 → 眨眼后 2 秒」正确率 | 部分（描述统计） |
| 多模态时序模型、保形预测、语言模型报告 | — | 需临床数据，未做 |

实现约定（待专家确认）：

1. 正式测试沿用练习的阶梯规则，从练习结束档位开始；双眼同时观看。
2. 档位为小数视力 0.1–1.2，每档 0.1 logMAR；超出本机像素能力的小视标自动封顶并在报告注明。
3. 作答后间隔 300 ms 出下一题，不强制占满 2 秒，所以题数因人而异。
4. 「正常眨眼间隔 > 10 秒」与「10–16 次/分」（平均间隔约 3.75–6 秒）不能同时用于自然眨眼段，因此解释为 20 秒睁眼段的最长持续睁眼时间。
5. 视觉维持率 = 正式测试平均视力（按呈现时长加权，用 logMAR 计算后换算）/ 练习结束视力。候选阈值 0.85。
6. 视力下降时间 = 睁眼段视标比该段起始放大 ≥ 2 档的时刻。
7. 风险规则：4 项客观指标（眨眼频率、最长睁眼、视觉维持率、视力下降），异常 ≥ 3 项，或 ≥ 2 项且症状「经常/总是」→ 高；≥ 1 项 → 中；否则 → 低。

## 2 老视（研究内容二）

| 文档要求 | 实现 | 状态 |
|---|---|---|
| 面向 35 岁以上；采集年龄、性别、职业、近距用眼、眼病、屈光状态、矫正方式、近用 Add | 问卷，年龄 < 35 时给出提示 | 已对齐 |
| 手术史：SMILE / FS-LASIK / PRK、白内障、ICL、多焦点/EDOF，以及手术时间和术后矫正 | 多选具体术式 + 条件出现的时间/术后矫正输入 | 已对齐 |
| 双模式：标准（远用矫正、无 Add）/ 日常（保持近用或渐进镜） | 问卷末页选择；日常模式不输出调节年龄 | 已对齐 |
| 近视力约 40 cm，视标像素按屏幕尺寸、分辨率和实际距离换算 | 右眼 / 左眼 / 双眼，每级 4 题、对 3 题通过；按实测距离计算像素 | 已对齐（原有） |
| 移近法：由远向近缓慢移动，首次持续模糊时记录近点；记录移动速度并重复测量 | 改为连续移近：≥ 45 cm 起，点按「开始持续模糊」记录距离和最近 1 秒速度；速度 > 5 cm/秒本次不计；共 3 次；12 cm 内仍清晰记为范围外 | 已对齐（原为分档移近） |
| 不同距离的近视力，形成距离—视觉表现曲线 | 新增多距离任务：60 / 33 / 25 cm 双眼阈值，加上 40 cm 共 4 点 | 已对齐 |
| 调节灵敏度：远近交替，记录单位时间正确循环、反应时、错误率 | 50 / 25 cm 真实移动 60 秒（原有） | 已对齐 |
| 质控：距离、移动速度、头姿、光照，语音或动画提示 | 行动提示加入头姿和移近速度；各步有卡通演示与语音 | 已对齐（遮眼检测未做） |
| 15 − 0.25×年龄 作参考；工作距离需求 1/d 与调节储备；输出「基本匹配 / 较同龄人偏低 / 较早老视样下降」 | `PresbyopiaProtocol` + `ScreeningAssessment.presbyopia` | 已对齐 |
| 视觉功能年龄 / 调节年龄 | 用平均公式 18.5 − 0.3×年龄 反推，标注「参考、未经验证」，只在标准模式输出 | 部分 |
| 比较两种模式、长期档案 | 结果页读取上一次本机记录做对比 | 部分（无趋势图） |

实现约定：移近法视标取双眼 40 cm 阈值档位，最小不低于 0.5 档，并按 40 cm 固定物理尺寸；「较早老视样下降」= 年龄 < 45 且调节幅度 < 5 D（40 cm 阅读需求 2.5 D 的两倍）；调节灵敏度候选阈值为 3 次/分钟。

## 3 斜视（研究内容三）

| 文档要求 | 实现 | 状态 |
|---|---|---|
| 33 cm，超出 ±5 cm 提醒 | 门禁和行动提示 | 已对齐（原有） |
| ① 注视：中央动态闪烁、高对比度的卡通注视点，1–2 Hz；直径 3–5 岁约 2 cm、6–12 岁约 1.5 cm；持续 10–15 秒，至少 3 秒有效帧 | 黑底小瞳卡通目标，1.5 Hz 明暗闪烁；尺寸按年龄；12 秒；连续 3 秒有效才计算 | 已对齐 |
| 瞳孔中心—角膜映光偏移，分解为 HDE / VDE；1 mm ≈ 15Δ；头姿 < 10° | 每帧左右眼映光鼻侧偏心之差，以平均角膜直径 11.7 mm 作像素尺度，换算为 Δ；头姿 > 10° 的帧剔除 | 已对齐（尺度见约定） |
| 判定：水平 ≥ 10Δ 或垂直 ≥ 5Δ 且注视稳定 → 可疑偏斜 / 高度疑似 | 稳定条件为标准差 ≤ 5Δ / 2.5Δ（候选） | 已对齐 |
| ② 交替遮盖：遮右 2s → 去遮 2s；遮左 2s → 去遮 2s；右 1s、左 1s 交替 2 轮；卡通手掌或语音引导 | 9 个动作序列；语音逐步播报，界面显示保持计时和序列进度；协助者在动作的同时点按，记录真实时刻 | 已对齐 |
| 去遮盖后 0.5 秒内：偏移幅度（Δ）、复位速度（°/s）、残余偏移；再注视 ≥ 6Δ → 可疑阳性 | 按被解除遮盖的那只眼分别计算，取事件中位数判定 | 已对齐 |
| ③ 追踪：水平正弦 ±10°、周期 4 秒 × 2；垂直同上；45° 斜向直线往复 ±10°、周期 3 秒 × 2 | 按实测距离把角度换算为像素；斜向改为三角波（直线往复）；屏幕放不下时等比缩小并记录实际可显示角度 | 已对齐（受屏幕限制） |
| BSI = 0.5·r_h + 0.3·r_v + 0.2·(1 − d_norm)；< 0.7 可疑，< 0.5 明显异常 | 按原式计算；r_h 用水平段和斜向段，r_v 用垂直段和斜向段 | 已对齐（定义见约定） |
| 输出三级：未见异常 / 可疑阳性 / 高度疑似斜视；质量不足时拒判 | `labelFor(STRABISMUS)`；质量不足时显示「测试质量不佳，请重新测试」 | 已对齐 |
| ④ 远近注视切换 | 文档中带删除批注（批注 215、235） | 未做 |
| 参照物标定像素/毫米比；头姿校准视频；红蓝立体图 | — | 未做 |
| 深度学习定位、LightGBM 分层、SHAP、语言模型报告、儿童常模 | — | 需临床数据，未做 |

实现约定：

1. **鼻侧坐标**：原先用左右眼映光偏移的原始差值，它包含 2 倍 κ 角（约 0.4 mm × 2 × 15Δ ≈ 12Δ），会让正常人也触发 10Δ 阈值。现在改为「鼻侧偏心之差」，双眼对称的 κ 角相互抵消。注视点与前置摄像头在水平方向上对齐，所以水平方向的共轭注视误差很小。
2. **像素尺度**：每帧用虹膜直径作尺度（平均角膜直径 11.7 mm），替代文档的参照物标定；Δ 是估算值，结果中会注明。
3. **d_norm**：手机无法得到视轴在屏幕上的投影，改用双眼相对位置波动的 RMS 除以水平段眼动幅度，截断到 [0, 1]。原式中的相关系数可为负，因此 BSI 理论范围为 [−0.8, 1]，沿用原阈值时需注意这一点。
4. **追踪速度**：原文要求 ±10°、周期 4 秒，此时平均角速度约 10°/s、峰值约 15.7°/s，与原文 5–10°/s 有冲突；实现按幅度和周期执行，速度在报告中按平均值描述。
5. **遮盖时刻**：不使用动画的计划时刻冒充真实动作时刻，由协助者在动作的同时点按标记；被遮眼的光学点不可见属于预期，不计入质量分母。
