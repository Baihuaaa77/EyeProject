## 1. 任务① 注视稳定性测试（角膜映光法等效）—— 第一眼位静态显斜基线

| 环节 | 内容 | 来源 |
|---|---|---|
| 刺激 | 屏幕中央动态闪烁、高对比度卡通注视点 | 【文档】；**闪烁频率、卡通视标尺寸/视角【缺失】** |
| 时长 | 取 **3 秒内连续有效帧** | 【文档】 |
| 采集 | 实时定位瞳孔中心、角膜映光点（第 1 Purkinje 像，利用屏幕自身发光或前置闪光灯形成）、内眦/外眦参考点 | 【文档】 |
| 计算 | 每眼映光点相对瞳孔中心的偏移量 → 比较双眼对称性 → HDE（水平偏斜量，像素）/ VDE（垂直偏斜量）→ 标定换算为近似棱镜度（△） | 【文档】 |
| 判定 | 「若某一眼的映光点明显偏离瞳孔中心（如位于瞳孔缘外侧或内侧），则提示存在显性斜视」；持续 ≥10△（水平）或 ≥5△（垂直）→ 高度疑似斜视 | 【文档】 |
| 前置训练说明 | 合成样本训练（翻转/缩放/亮度扰动）应对肤色/光照/眼大小差异 | 【文档】 |

**缺失项**：闪烁频率与视标视角大小；映光点检测算法的精度要求；像素→△ 的换算系数与标定流程；**映光点偏移方向与斜视类型（内斜/外斜）的对应关系文档未说明**；「明显偏离」「位于瞳孔缘」的量化定义。

## 2. 任务② 交替遮盖诱发测试 —— 隐斜 / 间歇性斜视

| 环节 | 内容 | 来源 |
|---|---|---|
| 遮盖标记（原文两种） | ① 受试者掌心遮挡屏幕侧方摄像头区域，手机检测「摄像头被遮挡的瞬间」作为遮盖标记；② 屏幕局部黑屏模拟「遮盖」一单眼 | 【文档】 |
| 事件窗口 | 遮盖解除后 **0.5 秒内** | 【文档】 |
| 提取量 | 再注视运动：偏移幅度（△）、复位速度（°/s）、残余偏移量 | 【文档】 |
| 检测手段 | 光流 + 帧间差异 | 【文档】 |
| 判定 | 再注视偏移 **≥6△ → 可疑阳性**；「依据受试者正常对照数据建立的阈值」 | 【文档】；**正常对照常模数据不存在（依赖 ≥500 例对照研究）【缺失】** |

**按原文可见的缺口**：
- 方式①按字面为「遮挡摄像头」——遮挡期间画面状态、遮挡与眼动测量的衔接方式，文档未说明
- 方式②「屏幕局部黑屏」如何实现「遮盖一单眼」（双眼共看同一屏幕），文档未说明
- 遮盖次数、单次时长、左右顺序、由谁执行（受试者/家长）【缺失】
- 复位速度的数值范围【缺失】

## 3. 任务③ 水平/垂直动态追踪 —— 双眼协调

| 环节 | 内容 | 来源 |
|---|---|---|
| 刺激 | 亮色小球沿水平、垂直及斜向轨迹缓慢移动，速度 **5-10°/s** | 【文档】；**轨迹幅度、周期、随机性【缺失】** |
| 采集 | 双眼运动轨迹、追随平滑度、双眼位置差异 | 【文档】 |
| 指标 | 双眼运动方向一致性；主序眼与偏斜眼平均位置差；轨迹交叉相关性 → **双眼对称性指数 BSI**；追随平稳性 | 【文档】 |
| 判读 | 「BSI 显著低于正常范围提示双眼协调障碍」 | 【文档】；**正常范围【缺失】** |

**缺失项**：BSI 的计算公式；正常范围数值；轨迹幅度/周期的具体参数；追随平稳性的量化定义；「协调障碍」的判定界值。

## 5. 融合模型与三级判定

| 项 | 内容 | 来源 |
|---|---|---|
| 输入 | 四任务标志物 + 年龄 + 屈光状态 + 测试环境变量 | 【文档】 |
| 模型 | LightGBM / CatBoost / 贝叶斯层次模型 | 【文档】 |
| 训练标签 | 三棱镜交替遮盖斜视度（△）、同视机融合范围（°）、Titmus 立体视锐度（arcsec） | 【文档】 |
| 三级判定 | ≥10△(H) 或 ≥5△(V) → 高度疑似；≥6△ → 可疑阳性；其余 → 未见异常 | 【文档】 |
| 可解释性 | SHAP/LIME + 通俗报告 | 【文档】 |
| 拒判 | 质量不足/配合度低 → 重测提示 | 【文档】；**触发阈值【缺失】** |
| 性能目标 | 水平 ≥10△：敏感度 ≥85%、特异度 ≥80%；≥500 例验证；12 周重测一致性（ICC/加权 Kappa） | 【文档】 |
