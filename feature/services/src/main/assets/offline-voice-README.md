# 离线中文语音指令模型

- 模型：Vosk `vosk-model-small-cn-0.22`，原始模型未修改。
- 来源：https://alphacephei.com/vosk/models/vosk-model-small-cn-0.22.zip
- 模型说明与许可证：https://alphacephei.com/vosk/models
- 原始 ZIP SHA256：`3af8b0e7e0f835ae9d414ce5df580237a3cfb08d586c9fbbb0f7ff29ad5b14ba`
- 许可证：Apache-2.0，完整文本见 `offline-voice-LICENSE.txt`。
- 用途：手机无标准 Android 中文语音识别服务或服务失败时，离线识别测试作答短指令。模型随安装包提供；音频不保存、不上传。
- 应用首次使用时复制到私有的 `noBackupFilesDir`，避免将模型加入用户备份。
